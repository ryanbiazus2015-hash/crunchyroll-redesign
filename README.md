# Crunchyroll · Protótipo do redesign

Protótipo navegável de um redesign conceitual da Crunchyroll, feito como estudo de design.

**Projeto não oficial.** Não tem vínculo com a Crunchyroll e não é o site real. Os títulos, sinopses e dados são ilustrativos. As imagens dos animes pertencem aos respectivos detentores de direitos e foram usadas só para ilustrar o estudo. Quando falta uma imagem, o HTML mostra um bloco de cor no lugar.

Ver online: https://ryanbiazus2015-hash.github.io/crunchyroll-redesign/
